# PANGANARA
Panganara adalah platform web edukasi pangan untuk membantu pengguna memahami informasi gizi pada label kemasan, mengenali istilah bahan alergen, dan meninjau klaim kesehatan secara kritis. Fitur awalnya mencakup pencarian contoh, alat pemeriksaan edukatif, dan artikel. Analisis otomatisnya bersifat prototipe, bukan pengganti saran medis.
